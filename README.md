# UIKit — Apple Music UI Exploration

An iOS project built with **Swift and UIKit** to explore and practice building user interfaces using Apple's UIKit framework.

The project uses an Apple Music-inspired interface as a practical context for experimenting with UIKit components, screen layouts, navigation, and reusable UI elements.

## Overview

The main goal of this project was **learning UIKit through hands-on implementation** rather than building a production-ready music application.

The interface is inspired by Apple Music and includes different sections and screens that allowed me to experiment with common UIKit patterns and components.

## What I Explored

* Building interfaces with **UIKit**
* `UIViewController` and view lifecycle
* `UITableView` and custom table view cells
* Storyboards and XIBs
* Tab-based navigation
* Reusable UI components
* Auto Layout and view positioning
* Custom UI elements and extensions
* Organizing screens into different sections
* Working with models to represent application data

## Project Structure

The project is organized around different sections of the application:

```text
NanoUIKit/
│
├── Browse Tab/
├── Favorites/
├── LibraryTab/
├── Model/
├── Extensions/
│
├── MusicPlaying.storyboard
├── FavoritesTableViewCell.swift
├── FavoritesTableViewCell.xib
├── LyricsTableViewCell.swift
└── AppDelegate.swift
```

The different sections were used to experiment with UIKit in different UI scenarios rather than keeping the project limited to a single screen.

## UI Components

The project makes use of several UIKit building blocks, including:

* View controllers
* Table views
* Custom table view cells
* Storyboards
* XIB files
* Tab-based interfaces
* Auto Layout
* Images and asset catalogs
* Custom extensions

For example, custom table view cells are used for presenting content such as favorites and lyrics, providing an opportunity to work with reusable views and UIKit's table view APIs.

## Technologies

## Purpose

This project was created as a **learning project while studying iOS development with UIKit**.

Rather than focusing on backend functionality or a complete production application, the goal was to become more comfortable with UIKit by recreating different parts of a familiar application interface and experimenting with the framework's components.

## Running the Project

1. Clone the repository.
2. Open `NanoUIKit.xcodeproj` in Xcode.
3. Select an iOS Simulator or connected device.
4. Build and run the application.
